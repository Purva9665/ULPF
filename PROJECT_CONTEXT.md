## 1. PROJECT GOAL

Build a **vendor-agnostic, enterprise-grade log pre-processing framework** that:
- Ingests logs from ANY hardware or software source (firewalls, IDS, OS, cloud, apps)
- Parses and normalizes them into a **universal event schema** (losslessly)
- Runs **ML-based anomaly detection** (Isolation Forest + Shannon Entropy)
- Routes security-relevant events to a **SIEM database** and all events to a **Data Lake**
- Is deployable in a completely **air-gapped environment** (no internet dependencies at runtime)
- Is packaged in **Docker** (platform-independent)
- Provides a **real-time dashboard** showing the pipeline in action

## 3. ARCHITECTURE

### Pipeline Flow (7 Stages)

```
Log Sources (12 sample logs across 9 vendors)
    |
    v
[1] INGEST      — Collect raw log, compute SHA-256 hash, create RawPayload
    |
    v
[2] DETECT      — Auto-detect log format using ParserRegistry (confidence scoring)
    |
    v
[3] PARSE       — Extract structured fields using source-specific parser
    |
    v
[4] NORMALIZE   — Map to ULPFNormalizedEvent universal schema
    |
    v
[5] VALIDATE    — JSON Schema validation, DQI (Data Quality Index) scoring 0-100
    |
    v
[6] STORE       — Write to:
    |               - ulpf_events.db  (primary / backward-compat, SQLite WAL)
    |               - ulpf_siem.db    (SIEM events only — anomaly>=0.60, DENY/BLOCK, HIGH severity)
    |               - ulpf_datalake.db (ALL events — long retention)
    v
[7] ML          — IsolationForest anomaly detection, Shannon entropy, score 0.0-1.0
    |
    v
EXPORTS         — Elastic ECS / Splunk HEC / OCSF / Parquet formats
    |
    v
WebSocket broadcast -> Frontend real-time dashboard
```

### Enterprise Architecture (PostgreSQL target)

```
Log Sources -> Collectors (rsyslog/Beats/OTel) -> Apache Kafka (KRaft)
    -> ULPF Processing Layer
    -> EventRouter (classify: SIEM or Data Lake)
    -> ulpf_siem (PostgreSQL + TimescaleDB)   [security events only]
    -> ulpf_datalake (MinIO + Apache Parquet) [all events]
```

### Storage Architecture (Three-Database Model)
- **ulpf_raw** — Append-only raw event landing zone (write: svc_collector only)
- **ulpf_siem** — Security events (ML>=0.60, DENY/BLOCK, HIGH/CRITICAL severity, security category)
- **ulpf_datalake** — All events (long retention, queryable via DuckDB/Spark)

### Routing Logic (EventRouter)
Events go to SIEM if ANY of:
1. ML anomaly_score >= 0.60
2. Category in: network_attack, authentication_attack, web_exploit, data_exfiltration, privilege_escalation, malware, dos, reconnaissance
3. Action in: deny, block, drop, reject, alert, quarantine
4. Destination port in: 22, 23, 445, 3389, 6379, 1433, 3306, 5432, 27017, 2375, 4444
5. Severity is HIGH or CRITICAL

ALL events always go to Data Lake regardless.
